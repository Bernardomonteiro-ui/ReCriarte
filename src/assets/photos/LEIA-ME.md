# Fotos reais da ReCriarte

Coloque aqui as fotos reais (JPG/PNG/WebP, idealmente ≥ 2000px no lado maior).
O site converte automaticamente para AVIF/WebP em vários tamanhos.

Os nomes de arquivo são referenciados em `src/data/*.ts` (campo `photo`).
Enquanto um arquivo não existir, o site mostra o desenho técnico correspondente.

Sugestão de nomes (subpastas são permitidas):

- hero/hero.jpg                      → imagem principal do Hero
- servicos/manutencao.jpg            → reparo / ferragem
- servicos/adaptacao.jpg             → transformação
- servicos/montagem.jpg              → equipe montando
- servicos/sob-medida.jpg            → detalhe / fabricação
- recriar/antes.jpg, recriar/intervencao.jpg, recriar/depois.jpg
- antes-depois/<projeto>-antes.jpg, antes-depois/<projeto>-depois.jpg
- projeto-execucao/<projeto>-projeto.jpg, projeto-execucao/<projeto>-execucao.jpg
- trabalhos/<projeto>/01.jpg, 02.jpg ...
- equipe/patrick.jpg, equipe/maycon.jpg

NUNCA use foto de banco de imagens como se fosse trabalho da ReCriarte.
